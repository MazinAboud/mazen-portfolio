SQL Join Types

MySQL · PHP Applications

Inner Join

Only matching rows in both tables.
SELECT * FROM A JOIN B ON A.id=B.id;

Left Join

All of A, plus matches from B.
SELECT * FROM A LEFT JOIN B ON A.id=B.id;

Right Join

All of B, plus matches from A.
SELECT * FROM A RIGHT JOIN B ON A.id=B.id;

Full Outer Join

Every row from both tables.
SELECT * FROM A LEFT JOIN B … UNION …
MySQL has no native FULL OUTER JOIN — it is emulated with a UNION of a LEFT and a RIGHT join. Also comfortable with SELF JOIN, prepared statements, and subqueries.
